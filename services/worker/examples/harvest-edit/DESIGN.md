# Meridian Market — design principles

How Meridian looks and feels at point of sale. These are interpretive
principles: the locked palette, fonts and hard rules (contrast floor,
minimum sizes, mandatory items) live in the brand profile and are enforced
by validation. Compositions are judged against *this* document in critique.

## The brand in one line

A market stall dressed by an editor — warm, seasonal, unhurried. Premium
through restraint, never through decoration.

## Composition

- Generous margins and real whitespace. If a layout feels efficient, it is
  too full. One hero element per piece; everything else supports it.
- Asymmetry over centring. Centre only single-line statements — never
  stacks of copy.
- Build a clear entry point: the eye should land on the headline or the
  hero image first, price second, everything else last.
- Let colour fields do the structural work. Prefer one large confident
  block of colour to several small panels.

## Type

- The serif (Canela / Liberation Serif) is for the headline moment only —
  large, few words, sentence case. Never letterspace it, never set body
  copy in it.
- The sans (Söhne / Liberation Sans) carries information: subheads, body,
  price, legal.
- Price is typographic — set it large and flat in Ink or HarvestPlum.
  No starbursts, no bursts, no angled price flashes, no "WAS/NOW" boxes.
- No more than two type sizes within one information group.

## Colour

- Bone is the default field. HarvestPlum is the anchor dark — headlines,
  full-bleed fields, the serious moments.
- OrchardRust and GoldenOchre are seasonal accents: one leads per piece,
  never both loud at once.
- SageMist is quiet air — soft panels and backgrounds, never text.
- CopperSpot is a finishing touch (thin rules, small marks) — a garnish,
  not an ingredient.

## Imagery

- Produce is photographed as still life: soft daylight, honest shadows,
  no saturation push.
- Images run full-bleed or sit generously in Bone. Never box an image in
  a thin keyline; never tilt, fade or feather it.

## Don't

- No gradients, no drop shadows, no outlined or stroked type.
- No decorative flourishes to fill silence — if a corner wants an
  ornament, leave it empty.
- Nothing "shouts": urgency comes from scale and space, not exclamation
  marks or capital letters.
