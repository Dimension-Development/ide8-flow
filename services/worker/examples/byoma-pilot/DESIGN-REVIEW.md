# BYOMA pilot — design review scorecard

Use one completed scorecard per concept before refinement. Technical validity
does not equal creative approval.

| Dimension | 1 — stop | 3 — adjust | 5 — go | Score | Notes |
|---|---|---|---|---:|---|
| Brand authenticity | Could belong to any brand | Some approved cues, but not distinctive | Unmistakably BYOMA within approved rules |  |  |
| Composition | Image/copy relationship feels accidental | Hierarchy works but needs balancing | Intentional, balanced visual relationship |  |  |
| Typography | Unclear, generic or illegible hierarchy | Mostly legible with visible tuning needed | Confident, characteristic, clearly legible hierarchy |  |  |
| Imagery | Wrong asset, crop or focal point | Asset works but crop/scale needs direction | Selection, crop, focal point and scale are right |  |  |
| Sophistication | Generic or visibly templated | Competent but lacks a distinctive decision | Polished, specific and non-generic |  |  |
| Production | Unsafe or incomplete package | Minor production fixes required | Technically safe and correctly packaged |  |  |
| Craft effort | More than 60 minutes to make client-ready | 15–60 minutes of directed finishing | Under 15 minutes of finishing |  |  |
